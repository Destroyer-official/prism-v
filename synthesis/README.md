# Synthesis notes

This directory is the planning and research corpus that preceded the current
code. It contains plan comparisons, architecture proposals, and UI blueprints.
It is **not** a description of the implemented system and it is not a test
report.

Some documents state that phases are "100% complete" or that features are
"verified". Those statements refer to the planning process unless they cite a
command or test output in `docs/VERIFICATION.md`. For the current state of the
code, use:

- [README.md](../README.md) for what the repository contains
- [docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md) for implemented modules
- [docs/VERIFICATION.md](../docs/VERIFICATION.md) for what was built and run
- [docs/MATHEMATICAL_INVARIANTS.md](../docs/MATHEMATICAL_INVARIANTS.md) for
  tested properties

Planning documents are kept for traceability. They may contain targets,
estimates, and proposals that were never implemented.
